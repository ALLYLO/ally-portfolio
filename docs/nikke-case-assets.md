## Playbook and tracking

The supplied playbook image still contained a readable internal link. Neither that image nor the original private documents are included in this public repository. The page instead displays a clearly labeled sanitized English transcription of the reporting workflow, with two short Chinese source excerpts available through the native disclosure control. It is not presented as an original screenshot. A verified, permanently redacted screenshot can replace this transcription in a later change if desired.

The creator table is labeled as an anonymized illustrative sample and uses only the three example rows provided in the implementation brief. It does not expose real creator identities or private account information.

The two View Post links use the owner-supplied Reddit URLs, open a new tab, and include `noopener noreferrer`, visible hover feedback, and keyboard focus styling. Post counts are a supplied snapshot; no live metrics are fetched.

Claim status is maintained in `docs/context/OPEN_QUESTIONS.md` rather than duplicated here.
