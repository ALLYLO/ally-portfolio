# Content and evidence guide

This file owns the standards for claims in the Portfolio. The source code shows what the page currently says; its presence is not proof that a claim is accurate, personally attributable, or cleared for publication.

## Claim gate

Before describing a business metric or outcome as confirmed, record all four:

1. Source: the evidence that supports the value.
2. Definition: the population, period, units, exclusions, and calculation.
3. Personal attribution: what the Portfolio owner did, versus team, client, or dataset scope.
4. Public permission: whether the wording and supporting material may be published.

If any element is missing, use Needs confirmation. Do not turn candidate counts into qualified, contacted, signed, or personally delivered results. Do not substitute a different metric merely because its number is similar.

Keep internal records, identity mappings, raw evidence, private contacts, and confidential terms outside this public repository. Anonymization alone does not establish permission to publish. Use only approved, appropriately scoped summaries on the website.

The specific currently displayed Creator Marketing claims awaiting this gate are listed once in OPEN_QUESTIONS.md. Approved wording, once established, should be maintained in the website source; this guide owns the rule rather than a duplicate copy of page text.
