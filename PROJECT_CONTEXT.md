# Portfolio project context

This repository is the sole canonical working repository for the Portfolio website. The enclosing workspace and older outputs are historical references, not alternative working copies. The website implementation lives in index.html, assets/, and prototypes/creator-screening/. README.md owns local preview and publishing instructions.

## How to read the project

- AGENTS.md gives Codex its durable working rules.
- README.md explains how to run, preview, and publish the site.
- docs/context/CONTENT_GUIDE.md owns standards for content claims and public evidence.
- docs/context/DESIGN_GUIDE.md holds only approved, durable design constraints.
- docs/context/DECISIONS.md records important decisions explicitly confirmed by the Portfolio owner.
- docs/context/OPEN_QUESTIONS.md tracks candidates and information that still needs confirmation.
- docs/context/TODO.md tracks work to do; it is not a fact source.

## Status vocabulary

- Currently implemented: observable in current source. This describes the page, not the truth or approval of a business statement.
- Confirmed: explicitly approved project decisions, or business claims whose source, definition, personal attribution, and permission to publish have all been established.
- Candidate: proposed or experimental; it is not approved for use as a durable project fact.
- Historical: an older or superseded version kept for traceability; it does not override current source.
- Needs confirmation: evidence, scope, approval, or public-use permission is missing or conflicting.

Current source determines implementation state. Owner-confirmed decisions determine project policy. Historical discussions may explain a choice but do not confirm it. Do not infer missing biography, results, or design decisions.
