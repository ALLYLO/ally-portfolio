# Portfolio agent entry point

Before any Portfolio task, read this file, then `docs/context/OPERATING_RULES.md`, and complete its mandatory preflight. Then read only the canonical context and source files needed for the task, starting with `PROJECT_CONTEXT.md` for the project baseline; use `README.md` for preview and deployment work. Do not modify anything before the preflight passes.

`ally-portfolio/` is the sole Portfolio Git scope. Confirm its Git root before Git operations; never use the enclosing repository for Portfolio changes.
